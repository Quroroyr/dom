# Cloud House

Облачный дом из одной SDF-массы: клоки реально отрываются, дом разбирается до скелета.
Three.js + three-mesh-bvh, GSAP, Lenis, сборка на Vite.

## Запуск

```
npm install
npm run dev        # http://127.0.0.1:5200
```

Или `start.cmd` — production-сборка и превью на http://127.0.0.1:5201.
