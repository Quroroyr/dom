# Cloud House

**Открыть сайт:** https://quroroyr.github.io/dom/

Интерактивный облачный дом в браузере. Дом собран из одной мягкой облачной массы (101 клок),
и её можно трогать руками: отрывать куски, бросать их, разбирать дом до каркаса, красить
и собирать обратно.

## Что умеет

- **Сцены вместо прокрутки**: House · Touch · Inside · Apart · Material · Weather, плюс Paint.
- **Отрыв кусков** с тянущимися волокнами. Оторванный кусок можно двигать, крутить и бросать,
  он сталкивается с домом и не проходит сквозь стены.
- **Разборка**: фасад поднимается, внутри видна комната; режимы «по слоям» и «разлёт».
- **Краска** кистью прямо по объёму: 12 цветов, ластик, отмена (Ctrl+Z). Краска остаётся
  на куске, даже если его оторвать.
- **Два материальных мира**: облако и трава (дёрн с землёй, ветер, пыльца).
- **Погода и небо**: смена времени суток и палитры.
- **Звук материалов**: синтезируется в браузере через Web Audio, звуковых файлов нет.
- Работает на телефоне и на слабых ПК: пять уровней качества (Ultra → Safe), уровень
  подбирается сам по реальному времени кадра и запоминается для устройства.

## Управление

| Действие | Мышь / клавиши |
|---|---|
| Щипнуть, оторвать кусок, рисовать | левая кнопка |
| Повернуть камеру вокруг дома | правая кнопка |
| Приблизить / отдалить | колесо |
| Кусок в руке: глубина / вращение | колесо / правая кнопка при зажатой левой |
| Сцены | ← / → или 1–6 |
| Варианты сцены | ↑ / ↓ |
| Собрать дом обратно | R |
| Домой | Esc |

Параметры адреса:

- `?skip` — без интро;
- `?quality=ultra|high|medium|low|safe` — зафиксировать уровень качества (`auto` — подбор, по умолчанию);
- `?perf` — панель производительности: FPS, время кадра, уровень, бенчмарк по сценам
  и кнопка «Copy performance report» (отчёт только копируется в буфер, никуда не отправляется).

## Как сделано

- **Three.js** — рендер. Форма дома задана SDF-полем (функцией расстояния),
  меш строится из поля в **Web Worker**, чтобы не подвисал интерфейс.
- **three-mesh-bvh** — быстрые попадания луча по мешу (касания, кисть).
- Свои шейдеры: ворс из оболочек, запечённый свет, краска в 3D-текстуре.
- Постобработка: bloom, глубина резкости на крупных планах, виньетка, зерно.
- Своя мягкая физика кусков: столкновения с домом по SDF-полю, отскок, скольжение.
- **GSAP** — переходы между сценами.
- Шрифты **Fraunces** и **Geist** (Fontsource), сборка **Vite**.
- Картинок и 3D-моделей нет: всё, что на экране, строится кодом.

## Запуск у себя

Нужен [Node.js](https://nodejs.org/) 20 или новее.

```
git clone https://github.com/Quroroyr/dom.git
cd dom
npm install
npm run dev
```

Откроется на http://127.0.0.1:5200. На Windows можно просто запустить `start.cmd`: он соберёт
сайт и откроет готовую версию на http://127.0.0.1:5201.

Нужен браузер с WebGL 2 (свежий Chrome, Edge или Firefox).
